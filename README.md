# منصة حل كيريو التلقائي (Qureo Auto-Solver Platform)

نظام متكامل يتكون من:
1. **واجهة ويب سريعة وعصرية (Frontend):** متوافقة مع الموبايل والكمبيوتر ونظام الخطوات.
2. **سيرفر الطابور والمعالجة (Backend API):** مبني بـ FastAPI ويدير طابور الطلاب (Queue).
3. **محرك الأتمتة (Playwright Engine):** للتعامل مع متصفح كيريو الخفي.
4. **بنك الحلول (Solutions Bank):** ملف JSON يحتوي على أكواد المستويات الـ 42.
